## Установка

1. Положите `KineticMenus.jar` в `plugins/` и запустите сервер.
2. Откройте в игре `/showcase`: там все эффекты, по кнопке на каждый.
3. Загляните в `plugins/KineticMenus/menus/`. Готовые `navigator.yml`, `shop.yml` и `shop-tools.yml` удобно брать за основу своих меню.

Нужны Paper или Folia 26.2 и Java 25. PlaceholderAPI, Vault (или VaultUnlocked) с плагином экономики и Floodgate — по желанию.

За файлами меню плагин следит сам: сохранили файл — через мгновение изменения в игре, даже в меню, которые сейчас открыты у игроков. `/kmenu reload` делает то же вручную и заодно перечитывает `config.yml` и языковые файлы.

## Из чего состоит файл меню

Каждый `.yml` в `menus/` — одно меню, подпапки тоже читаются. Имя файла — id меню: `menus/shop/tools.yml` — это меню `tools`. Два файла с одинаковым именем в разных папках конфликтуют, один из них пропускается с предупреждением.

```yaml
title: "<gradient:#F2C14E:#FF6B6B>Магазин"
rows: 5
commands: [shop]

open:
  effect: fall

ambient:
  effect: pulse

filler:
  material: black_stained_glass_pane
  hide-tooltip: true

buttons:
  bread:
    slot: 20
    material: bread
    name: "<#F2C14E>Хлеб"
    on-click: ["console: give {player} minecraft:bread 16"]
    effect: sparkle
```

Ошибка в файле никогда не мешает меню загрузиться. В консоли будет файл, ключ и что ожидалось:

```
menus/shop.yml, buttons.bread.effect: 'sparkel' is not one of [none, press, flash, shake, ripple, sparkle].
```

## Ключи меню

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `title` | id меню | Заголовок в MiniMessage. `{player}` и PlaceholderAPI работают, `{phase}` нет: Paper не умеет менять заголовок открытого меню. |
| `rows` | `3` | Высота, от 1 до 6. |
| `command` / `commands` | нет | Команды, открывающие меню, без слэша: `commands: [shop, store]`. |
| `permission` | нет | Право на открытие меню. Короткая запись строки `permission:` в `open-if`. |
| `open-if` | нет | [Условия](#условия) для открытия. |
| `on-deny` | сообщение `no-access` | [Действия](#действия) вместо открытия, если `open-if` не выполнено. |
| `open.effect` | `none` | [Эффект открытия](#открытие). |
| `open.ticks` | `16` | Длина открытия, от 1 до 100 тиков (20 тиков — секунда). |
| `open.easing` | `auto` | Кривая скорости: `auto` (равномерно), `ease-in`, `ease-out`, `ease-in-out`. |
| `open.sound` | `auto` | [Звуки](#звуки) открытия. |
| `ambient.effect` | `none` | [Фоновый эффект](#фон). |
| `ambient.speed` | `2` | Тиков на шаг фонового эффекта, от 1 до 40. |
| `refresh` | `2` | Тиков между перерисовками градиентов, плейсхолдеров и `show-if`, от 1 до 200. Перерисовываются только меню, где всё это есть. |
| `filler` | нет | [Иконка](#иконки-и-текст) для слотов без кнопок. Без неё они пустые. |
| `accent` | голубая панель | Яркий цвет эффектов: фронт волны, искры, огоньки рамки, кромка при открытии. |
| `trail` | серая панель | Бледный цвет, который эффекты оставляют за собой. |
| `buttons` | нет | [Кнопки](#кнопки), по разделу на каждую. |

## Кнопки

```yaml
buttons:
  vip-crate:
    slot: 24
    priority: 1
    material: ender_chest
    name: "<gradient:#C38BFF:#7FB3FF>VIP-сундук"
    show-if: ["permission: shop.vip"]
    click-if: ["money: 250"]
    on-click:
      - "take-money: 250"
      - "console: give {player} minecraft:diamond 2"
    effect: sparkle
    on-deny: ["message: <#FF6B6B>Нужно 250."]
```

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `slot` / `slots` | нет | Номера слотов с нуля, слева направо, сверху вниз. Можно диапазоны: `slots: ["0-8", 36, "45-53"]`. Кнопка без слота внутри меню пропускается. |
| `priority` | `0` | Если на слот претендуют несколько кнопок, показывается та, у которой число меньше и `show-if` выполнено. |
| ключи иконки | | `material`, `amount`, `name`, `lore`, `glint`, `model`, `hide-tooltip`, см. [Иконки и текст](#иконки-и-текст). |
| `pressed` | иконка со свечением | Как выглядит кнопка, пока её «вдавливает» эффект `press`. |
| `show-if` | нет | [Условия](#условия), при которых кнопка вообще видна. |
| `click-if` | нет | Условия, при которых клик срабатывает. |
| `permission` | нет | Короткая запись строки `permission:` в `click-if`. |
| `effect` | `press` | [Эффект нажатия](#нажатия). |
| `sound` | `auto` | [Звуки](#звуки) нажатия. |
| `on-click` | нет | [Действия](#действия) на любой клик. |
| `on-left-click`, `on-right-click`, `on-shift-left-click`, `on-shift-right-click` | `on-click` | Действия на определённый клик. Если своего списка нет, берётся `on-click`. |
| `deny-effect` | `shake` | Эффект, если `click-if` не выполнено или не хватило денег. |
| `deny-sound` | `auto` | Звуки отказа. |
| `on-deny` | нет | Действия при отказе. Если их нет, при нехватке денег придёт `not-enough-money`, в остальных случаях кнопка просто трясётся. |

Клики чаще раза в 3 тика не засчитываются, поэтому двойной клик не купит дважды. Клик во время открытия пропускает анимацию.

Предметы в меню ненастоящие: ни клик, ни shift-клик, ни цифры, ни перетаскивание, ни выбрасывание ничего не вынимают и не кладут.

## Иконки и текст

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `material` | `stone` | Любой предмет. Неизвестное имя заменяется барьером с предупреждением. |
| `amount` | `1` | Число на предмете. |
| `name` | имя предмета | Название в MiniMessage. |
| `lore` | нет | Строки описания в MiniMessage. |
| `glint` | `false` | Свечение зачарования без зачарований. |
| `model` | нет | Модель предмета из ресурспака, `namespace:path`. |
| `hide-tooltip` | `false` | Без всплывающей подсказки, удобно для заполнителя. |

Названия и описание не курсивные, если не написать `<italic>`. В тексте работают:

- `{player}` — ник игрока;
- плейсхолдеры PlaceholderAPI, если он установлен;
- `{phase}` — число, которое за две секунды проходит от -1 до 1. Поставьте его последним в градиент, и цвета поплывут: `<gradient:#5EE7DF:#B490CA:#5EE7DF:{phase}>Магазин`. Если начать и закончить градиент одним цветом, переход будет без шва.

## Эффекты

### Открытие

| Эффект | Что видит игрок |
|---|---|
| `none` | Меню сразу. |
| `cascade` | Ряд за рядом сверху, каждый ряд заезжает слева. |
| `wave` | Кольца от центра наружу. |
| `spiral` | По рамке и внутрь. |
| `typewriter` | Слот за слотом, в конце звонок. |
| `scatter` | Кнопки слетаются из случайных слотов. |
| `shuffle` | Кнопки крутятся, как барабаны игрового автомата, и останавливаются по столбцам. |
| `fall` | Кнопки падают сверху, сначала левые столбцы. |
| `burst` | Кнопки разлетаются из центра. |
| `slide-left`, `slide-right`, `slide-up`, `slide-down` | Прошлое меню уезжает, это заезжает следом. См. [Страницы и переходы](#страницы-и-переходы). |

`cascade`, `wave`, `spiral` и `typewriter` проявляют заполнитель вместе с кнопками, а чуть впереди бежит искра цвета `accent`. `scatter`, `fall`, `burst` и `shuffle` двигают только кнопки поверх заполнителя, который виден с первого кадра, и оставляют за ними след `trail`.

`open.ticks` — длина открытия. Кнопки, которым лететь недалеко, прилетают раньше, а не ползут, поэтому `scatter`, `fall` и `burst` могут закончиться быстрее. Слайды всегда сдвигаются на один столбец (или ряд) за тик.

### Нажатия

| Эффект | Что видит игрок |
|---|---|
| `none` | Ничего. |
| `press` | Кнопка на миг вдавливается (показывается `pressed`). |
| `flash` | Две вспышки свечения. |
| `ripple` | Кольцо цвета `accent` расходится по пустым слотам, за ним `trail`. |
| `sparkle` | Кнопка светится, вокруг разлетаются искры. Для покупок и наград. |
| `shake` | Кнопка дёргается влево-вправо. Отказ по умолчанию. |

Эффекты нажатия рисуют только на самой кнопке и пустых слотах, другие кнопки не трогают.

### Фон

| Эффект | Что видит игрок |
|---|---|
| `none` | Неподвижный фон. |
| `chase` | По рамке бегут огоньки, на больших меню — два. |
| `twinkle` | Пустые слоты вспыхивают по одному вразнобой. |
| `pulse` | Рамка медленно загорается и гаснет. |

Фоновые эффекты используют только пустые слоты и замирают, пока меню открывается.

Игроки, выключившие анимации (`/kmenu animations off`), и игроки Bedrock эффектов не видят: меню открываются сразу, кнопки не двигаются. Звуки остаются.

## Звуки

У каждого эффекта свои звуки: падающие колокольчики у `cascade`, звонок печатной машинки, щелчки автомата у `shuffle`, шелест страницы у слайдов, щелчок нажатия и отпускания у `press`, низкое двойное «нет» у `shake`. `open.sound`, `sound` и `deny-sound` принимают:

- `auto` — звуки эффекта (по умолчанию);
- `none` — тишина;
- свои звуки, по строке на каждый: `"ключ громкость высота задержка"`. Громкость и высота по умолчанию 1, задержка 0 тиков.

```yaml
sound:
  - "block.note_block.chime 0.6 1.2"
  - "block.note_block.chime 0.6 1.6 3"
```

Ключи — ванильные названия звуков, с `minecraft:` или без. Звуки меню идут в категории звуков интерфейса (UI). `sounds.volume` в `config.yml` меняет громкость всех сразу, `/kmenu sounds off` выключает их для одного игрока.

## Условия

`open-if`, `show-if` и `click-if` — списки, выполнены должны быть все строки.

| Строка | Выполнено, когда |
|---|---|
| `permission: shop.vip` | У игрока есть право. |
| `money: 100` | У игрока не меньше 100. Нужны Vault и плагин экономики, без них условие не выполняется никогда. |
| `placeholder: %player_level% >= 10` | Сравнение верно. Плейсхолдеры можно ставить с обеих сторон. |

Сравнения: `==`, `!=`, `>=`, `<=`, `>`, `<`. Числа сравниваются как числа, остальное как текст, и для текста работают только `==` и `!=`.

`!` в начале переворачивает строку: `"!permission: shop.vip"` выполнено для игроков без права.

`show-if` проверяется при каждой перерисовке и на следующем тике после клика, поэтому кнопка покажется сразу, как только у игрока будут право или деньги.

## Действия

Действия выполняются сверху вниз.

| Строка | Что делает |
|---|---|
| `message: <текст>` | Сообщение игроку в MiniMessage. |
| `console: <команда>` | Команда от имени консоли. |
| `player: <команда>` | Команда от имени игрока. |
| `sound: <ключ> [громкость] [высота]` | Звук игроку. |
| `open: <меню> [эффект]` | Открывает другое меню, с его собственным открытием или с указанным здесь эффектом. |
| `close` | Закрывает меню. |
| `refresh` | Сразу перерисовывает меню. |
| `take-money: <сумма>` | Списывает деньги, см. [Деньги](#деньги). |
| `give-money: <сумма>` | Начисляет деньги. |

В командах работают `{player}` и плейсхолдеры PlaceholderAPI, слэш в начале не мешает. `open` и `close` выполняются на следующем тике: подменить меню прямо во время клика по нему нельзя.

## Деньги

```yaml
click-if: ["money: 20"]
on-click:
  - "take-money: 20"
  - "console: give {player} minecraft:bread 16"
on-deny: ["message: <#FF6B6B>Нужно 20."]
```

Прежде чем выполнить хоть одно действие клика, KineticMenus складывает все `take-money` в нём и проверяет баланс. Если не хватает, не выполняется ничего, а кнопка показывает отказ. Ставьте `take-money` первым в списке: если экономика откажет в списании в последний момент, следующие за ним действия не выполнятся.

Работает с Vault или VaultUnlocked и любым плагином экономики, который с ними работает (EssentialsX и другие). Экономика ищется в момент покупки, поэтому порядок запуска плагинов не важен.

## Страницы и переходы

Слайд показывает, как прошлое меню уезжает, а новое заезжает на его место:

```yaml
# shop.yml
tools:
  slot: 26
  material: iron_pickaxe
  on-click: ["open: shop-tools slide-left"]

# shop-tools.yml
back:
  slot: 36
  material: arrow
  on-click: ["open: shop slide-right"]
```

В `open:` можно указать любой эффект, прошлое меню используют только слайды. Если меню открыто командой, слайд заезжает на пустой экран.

## Команды и права

| Команда | Право | По умолчанию |
|---|---|---|
| `/kmenu open <меню> [игрок]` | `kineticmenus.command.open`; для других игроков `kineticmenus.command.open.others` | все / op |
| `/kmenu animations <on\|off>` | `kineticmenus.command.animations` | все |
| `/kmenu sounds <on\|off>` | `kineticmenus.command.sounds` | все |
| `/kmenu list` | `kineticmenus.command.list` | op |
| `/kmenu reload` | `kineticmenus.command.reload` | op |
| `/kmenu import deluxemenus` | `kineticmenus.command.import` | op |

`/km` — короткая запись `/kmenu`. `kineticmenus.admin` даёт все админские команды. Выбор анимаций и звуков хранится на игроке и переживает перезапуск.

Командам меню (`commands:` в файле) своё право не нужно, используйте `permission` или `open-if` в самом меню. Команды меню, добавленных при работающем сервере, заработают после перезапуска: сервер регистрирует команды только при старте. `/kmenu reload` об этом предупредит.

## config.yml

```yaml
config-version: 2
language: ru
auto-reload: true
sounds:
  enabled: true
  volume: 1.0
bedrock-reduced-motion: true
```

| Ключ | Что делает |
|---|---|
| `language` | `ru` или `en`. Тексты лежат в `lang/`, их можно править; недостающие строки берутся из плагина. |
| `auto-reload` | Применять сохранённые файлы меню сразу. |
| `sounds.enabled` | Выключает все звуки меню для всех. |
| `sounds.volume` | Множитель громкости звуков меню, от 0 до 2. |
| `bedrock-reduced-motion` | Меню без анимаций для игроков Bedrock (Geyser с Floodgate): их клиент медленно перерисовывает сундуки, и быстрая анимация превращается в мерцание. |

При обновлении в ваш `config.yml` дописываются новые ключи, ваши значения остаются.

## Переезд с DeluxeMenus

1. Оставьте папку `plugins/DeluxeMenus` на месте (сам DeluxeMenus можно удалить).
2. Выполните `/kmenu import deluxemenus`.
3. Меню появятся в `plugins/KineticMenus/menus/imported/` и сразу загрузятся. В консоли будет список того, что стоит проверить.

Меню, для которых файл уже есть, не трогаются, так что импорт можно повторять.

| DeluxeMenus | KineticMenus |
|---|---|
| `menu_title`, `size`, `open_command`, `update_interval` | `title`, `rows`, `commands`, `refresh` |
| `open_requirement` | `open-if`, `on-deny` |
| `material`, `amount`, `slot`, `slots`, `priority` | те же ключи |
| `display_name`, `lore` (цвета `&` и `&#RRGGBB`) | `name`, `lore` в MiniMessage |
| `enchantments`, `enchantment_glint_override` | `glint: true` |
| `item_model`, `hide_tooltip` | `model`, `hide-tooltip` |
| `view_requirement` | `show-if` |
| `click_requirement` (или первое требование на отдельный клик) | `click-if`, `on-deny` |
| `click_commands`, `left_click_commands` и другие списки по кликам | `on-click`, `on-left-click` и так далее |
| `has permission`, `has permissions`, `has money`, `string equals`, `==`, `>=` и другие сравнения, с `!` | `permission:`, `money:`, `placeholder:` |
| `[player]`, `[console]`, `[commandevent]`, `[message]`, `[minimessage]`, `[openguimenu]`, `[close]`, `[refresh]`, `[sound]`, `[takemoney]`, `[givemoney]` | соответствующие действия |

Не переносится, о каждом случае есть строка в консоли: головы с текстурами и из плагинов (`head-`, `basehead-`, `hdb-` и подобные становятся головой игрока), `model_data`, `minimum_requirements`, `middle_click_commands`, задержки и шансы у действий, `[connect]`, `[broadcast]`, `[json]` и другие действия без замены, требования к предметам и опыту, требования на JavaScript, кнопки из воздуха. Перенесённые меню открываются эффектом `cascade`, поменяйте `open.effect` по вкусу.

## Вопросы

**Почему заголовок не анимируется?** Paper 26.2 не поддерживает смену заголовка открытого меню. Плагины, которые анимируют заголовок, переоткрывают меню на каждом кадре, и курсор прыгает в центр экрана.

**Работает ли на Folia?** Да. Каждое меню работает в потоке своего игрока.

**Не нагружает ли сервер?** Меню работает, только пока открыто, а игроку уходят лишь слоты, где предмет действительно сменился. Меню без градиентов, плейсхолдеров, `show-if` и фонового эффекта после открытия не отправляет ничего.

**Игрок жалуется на мерцание.** Возможно, он на Bedrock без Floodgate или просто любит спокойные меню: `/kmenu animations off` в его распоряжении.

**Где хранятся настройки игроков?** На самом игроке (persistent data), в папке плагина ничего не создаётся.
